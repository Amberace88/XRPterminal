================================================================================

XRP Terminal must remain non-custodial.

- hold XRP for users
- hold fiat for users
- hold crypto for users
- receive user deposits
- process withdrawals
- store seed phrases
- store private keys

- execute real trades in the MVP

- public XRPL addresses

- future supported public blockchain wallets
- future DeFi data sources
